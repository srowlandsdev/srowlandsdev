## THE ENGINEER

I'm a long-time game developer and DevOps Manager with a passion for engineering, automation and building practical software solutions.

I've been involved in game development since **2014**, working with Unity Engine and C#, while my professional career has evolved into managing DevOps environments and engineering infrastructure.

My work sits at the intersection of software development, infrastructure management and automation.

I enjoy building things from the ground up, improving development workflows and creating systems that make complex processes more reliable and repeatable.

### WHAT I DO

- 🎮 **Game Development** — Unity Engine, C# and development tooling.
- ⚙️ **DevOps Engineering** — Managing self-hosted infrastructure and delivery workflows.
- 🔄 **CI/CD** — Pipeline engineering and automation with Jenkins.
- 🏗️ **Infrastructure as Code** — Infrastructure provisioning and configuration with Terraform.
- 🐍 **Development** — C# and Python for applications, tools and automation.
